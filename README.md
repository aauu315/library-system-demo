# 图书管理系统｜数据结构课程设计

本项目为我的数据结构课程设计，使用 C++ 实现一个控制台图书管理系统。当前为课设正式提交的代码，并记录其中用到的数据结构与算法。



## 项目功能

- 图书管理：新增、删除、修改、查询、入库与出库。
- 读者管理：维护读者信息、封禁与解禁。
- 借阅管理：借书、还书、续借、逾期罚款计算。
- 预约管理：无库存时排队预约，归还后显示通知。
- 统计分析：借阅排行榜、库存统计、逾期记录与当前借阅统计。

项目采用本地文本文件保存数据，没有使用数据库。

## 数据结构与算法

| 使用位置 | 数据结构或算法 |
| --- | --- |
| 图书存储与编号索引 | `std::vector` 与手写二叉搜索树 BST |
| 读者存储与查询 | `std::vector` 与线性查找 |
| 借阅记录 | `std::list` |
| 每本图书的预约队列 | `std::map` 与 `std::deque`，按 FIFO 处理 |
| 借阅排行榜 | 手写快速排序 |

其中，BST 没有实现自平衡，最坏情况下会退化为线性查找；快速排序也存在 O(n²) 的最坏情况。标准容器使用 C++ 标准库，并非全部手写实现。

详细讲解见 [数据结构与算法详解](数据结构与算法详解.md)。

## 目录结构

```text
.
├── main.cpp                  # 程序入口与控制台菜单
├── include/                  # 头文件
│   ├── models/               # 数据模型
│   ├── repositories/         # 内存数据访问
│   ├── managers/             # 业务处理
│   └── utils/                # BST、排序、日期与文件工具
├── src/                      # 对应实现
├── data/                     # 脱敏后的课设演示数据
├── build.ps1                 # 简单编译脚本
├── README.md
└── 数据结构与算法详解.md
```

`main.cpp` 负责交互与初始化，Manager 处理业务，Repository 管理内存数据，Model 定义图书、读者、借阅与预约记录。实际文件读写由 `DataManager` 完成。正式版中未使用的 `FileIO.h` 也作为原始代码的一部分保留。

## 编译与运行

原项目主要在 Windows 环境下使用 MinGW g++，源码按 UTF-8 编码保存。需要支持 C++17 的 g++，并将其加入 PATH。

在项目根目录打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\build\library_system.exe
```

运行时保持工作目录为项目根目录，程序会从 `data/` 读取文本文件。请通过主菜单的 **5. 退出系统** 保存并退出；强制关闭程序或结束输入不能替代正常保存。

演示数据中的图书编号以 `B` 开头，读者编号以 `S` 或 `T` 开头，可直接查看 `data/` 文件了解可用编号。

## 留档说明

- C++ 源码保留正式提交版，不混入后续整理时增加的修复或业务调整。
- 数据文件仅对个人信息做脱敏，保留原有字段、编号和历史记录；其中可能存在课设调试遗留的数据状态。
- 姓名等演示字段已匿名化，仓库不包含个人身份、学校信息和原始提交压缩包。
- 这是课程设计留档，保留当时实现的局限，不作为实际图书馆业务系统使用。
- 当前不安排扩展；以后若继续开发，可在此归档版本的基础上另行推进。
